# Razi Ibrahim — Portfolio

A responsive, single-page portfolio built as a static site. It follows the dark, single-page structure of the existing portfolio while refocusing the content on Flutter and Android development, current experience, and the projects in the supplied résumé.

## Preview

Open `index.html` in a browser. The résumé download is included at `assets/Razi-Ibrahim-CV.pdf`.

## Publish with GitHub Pages

1. Add the contents of this folder to the root of the GitHub Pages repository.
2. In the repository settings, open **Pages** and select the branch and root folder used for the site.
3. Visit the published address after GitHub Pages finishes its build.

No build step or package install is needed. Google Fonts are optional; system font fallbacks are included.

## Before publishing

- Each project’s GitHub link currently opens the GitHub profile because individual repository URLs were not listed in the résumé. Replace those links with the specific project repositories when ready.
- The résumé file contains the contact information supplied in the attached PDF.
- Review the visible phone number and contact details before publishing publicly.
